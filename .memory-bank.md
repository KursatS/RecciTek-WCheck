# 🧠 Project Memory Bank: RecciTek WCheck

## 🎯 Project Overview
- **Core Purpose:** Roborock garanti servis merkezinde kullanılan masaüstü uygulama. Clipboard'dan seri numarası yakalayarak otomatik garanti sorgusu yapar, MH (Müşteri Hizmetleri) ile Kargo Kabul ekipleri arasında eksik bilgi taleplerini (ticket) yönetir, personel XP/seviye/prim takibi sağlar.
- **Target User:** Kargo Kabul personelleri (cihaz kabul, seri tarama, MH'ye bilgi talebi) ve Müşteri Hizmetleri personelleri (eksik bilgi tamamlama, müşteri iletişimi).
- **Success Criteria:** Sıfır elle veri girişi ile garanti kontrolü; ticket bazlı eksik bilgi akışının gerçek zamanlı çalışması; personel prim hesaplamasının otomatikleştirilmesi.

## 🛠 Tech Stack & Environment
- **Primary Language/Runtime:** TypeScript (strict), Node.js
- **Frameworks/Libs:** Electron 34 + electron-vite, Firebase (Firestore — gerçek zamanlı listener'lar), better-sqlite3 (yerel önbellek), jsdom (HTML parsing), xlsx (Excel okuma), jspdf (PDF rapor)
- **Infrastructure:** Firestore (tickets, users, priority_devices koleksiyonları), GitHub Releases (electron-updater ile otomatik güncelleme), garantibelgesi.recciteknoloji.com (garanti sorgulama sunucusu)
- **Dev Tools:** electron-vite, TypeScript 5.7, electron-builder (NSIS installer), Vite 6

## 🏗 Architecture & Design Patterns
- **High-Level Design:** Electron Main ↔ Preload (IPC Bridge) ↔ Renderer tek dosya SPA mimarisi.
  - `main.ts` → IPC handler hub, tray, clipboard izleme, Firestore listener yönetimi
  - `preload.ts` → contextBridge ile güvenli IPC açığı
  - `index-renderer.ts` → Ana renderer, sidebar SPA view yönetimi
  - `index.html` → Tüm view'lar tek HTML içinde `<section>` bazlı (history, tickets, profile, priority, bonus, admin, settings)
- **Data Model:**
  - **Firestore `tickets`:** `serial, model_name, model_color, missing_type, note, customer_name, aras_code, phone_number, status (pending|in_progress|completed), response, responded_by, created_by, is_hidden, hidden_by`
  - **Firestore `users`:** `username, password, fullName, role (kargo_kabul|mh), xp, level, isAdmin`
  - **Firestore `priority_devices`:** `serial, customer_name, description, created_by`
  - **SQLite (yerel önbellek):** Garanti sorgu sonuçları
- **Key Constraints:** Firebase ücretsiz kotası → okuma/yazma sayısı minimize edilmeli; waiting timer client-side hesaplanıyor (Firestore yükü sıfır).
